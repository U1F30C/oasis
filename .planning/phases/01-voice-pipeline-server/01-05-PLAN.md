Create `src/client/src/audio.ts` — the browser audio utility module. No codebase analog exists; implement from RESEARCH.md Pattern 4 and PATTERNS.md audio.ts section.

This module has two exports:

**`captureAndSendAudio(blob: Blob, ws: WebSocket): Promise<void>`**
- Accepts a Blob from MediaRecorder (webm/opus format — NOT WAV)
- Decodes with AudioContext.decodeAudioData()
- Resamples to 16kHz mono using OfflineAudioContext
- Sends the raw Float32Array PCM bytes as binary WebSocket frame
- Closes the AudioContext after send

**`playWavBuffer(arrayBuffer: ArrayBuffer): Promise<void>`**
- Accepts an ArrayBuffer containing WAV bytes from server
- Decodes with AudioContext.decodeAudioData()
- Plays via AudioBufferSourceNode connected to destination
- Returns a Promise that resolves when playback ends (onended)
- Closes the AudioContext after playback

```typescript
/**
 * Browser audio utilities for Oasis voice client.
 *
 * captureAndSendAudio: decode MediaRecorder blob → resample to 16kHz mono → send PCM over WebSocket
 * playWavBuffer: decode WAV bytes from server → play via Web Audio API
 */

/**
 * Decode a MediaRecorder Blob (webm/opus or ogg/opus), resample to 16kHz mono Float32Array,
 * and send as a binary WebSocket frame.
 *
 * The server expects raw Float32Array bytes (little-endian, 16kHz, mono).
 */
export async function captureAndSendAudio(blob: Blob, ws: WebSocket): Promise<void> {
  const arrayBuffer = await blob.arrayBuffer();
  const audioCtx = new AudioContext();

  let decoded: AudioBuffer;
  try {
    decoded = await audioCtx.decodeAudioData(arrayBuffer);
  } catch (err) {
    await audioCtx.close();
    throw new Error(`Failed to decode audio blob: ${err}`);
  }

  const TARGET_RATE = 16000;
  const offlineCtx = new OfflineAudioContext(
    1, // mono
    Math.ceil(decoded.duration * TARGET_RATE),
    TARGET_RATE,
  );

  const source = offlineCtx.createBufferSource();
  source.buffer = decoded;
  source.connect(offlineCtx.destination);
  source.start();

  const resampled = await offlineCtx.startRendering();
  const pcm = resampled.getChannelData(0); // Float32Array at 16kHz mono

  ws.send(pcm.buffer); // send underlying ArrayBuffer as binary frame

  await audioCtx.close();
}

/**
 * Decode WAV bytes received from the server and play via the Web Audio API.
 * Resolves when playback ends.
 */
export async function playWavBuffer(arrayBuffer: ArrayBuffer): Promise<void> {
  const audioCtx = new AudioContext();

  let buffer: AudioBuffer;
  try {
    buffer = await audioCtx.decodeAudioData(arrayBuffer);
  } catch (err) {
    await audioCtx.close();
    throw new Error(`Failed to decode server WAV: ${err}`);
  }

  return new Promise((resolve) => {
    const src = audioCtx.createBufferSource();
    src.buffer = buffer;
    src.connect(audioCtx.destination);
    src.onended = () => {
      audioCtx.close();
      resolve();
    };
    src.start();
  });
}
```

**`src/client/src/hooks/useVoiceWS.ts`** — React hook wrapping MediaRecorder + WebSocket client.

This hook encapsulates all audio and network logic. App.tsx only calls `connect`, `startRecording`, `stopRecording`, and reads `state`.

Key behaviors (from RESEARCH.md Code Examples lines 566-638 and PATTERNS.md ws.ts section):
- `connect(url)` — creates WebSocket with `binaryType = "arraybuffer"`, wires `onmessage` handler
- `startRecording()` — guard: only if `state === "idle"`; getUserMedia → MediaRecorder → collect chunks; sets a 30-second auto-stop timeout via `setTimeout` stored in `autoStopTimer` ref
- `stopRecording()` — clears the auto-stop timer via `clearTimeout(autoStopTimer.current)` before stopping the recorder; calls `recorder.stop()`
- `onstop` handler calls `captureAndSendAudio`
- `onmessage` handler: if text → parse ControlMessage, update state; if binary → call `playWavBuffer`, set state "playing", then "idle" on end
- State machine: idle → recording (on startRecording) → processing (on server "processing" message) → playing (on binary WAV received) → idle (on playback end)

Full hook implementation:

```typescript
import { useRef, useState, useCallback } from "react";
import { captureAndSendAudio, playWavBuffer } from "../audio.js";
import type { ControlMessage, PipelineState } from "../../../shared/protocol.js";

export function useVoiceWS() {
  const ws = useRef<WebSocket | null>(null);
  const recorder = useRef<MediaRecorder | null>(null);
  const chunks = useRef<Blob[]>([]);
  const autoStopTimer = useRef<number | null>(null);
  const [state, setState] = useState<PipelineState>("idle");
  const [error, setError] = useState<string | null>(null);

  const connect = useCallback((url: string) => {
    if (ws.current && ws.current.readyState === WebSocket.OPEN) return;

    ws.current = new WebSocket(url);
    ws.current.binaryType = "arraybuffer";

    ws.current.onopen = () => {
      console.log("[WS] Connected");
      setError(null);
    };

    ws.current.onmessage = async (e: MessageEvent) => {
      if (typeof e.data === "string") {
        const msg = JSON.parse(e.data) as ControlMessage;
        if (msg.type === "processing") setState("processing");
        if (msg.type === "error") {
          console.error("[WS] Server error:", msg.message);
          setError(msg.message);
          setState("idle");
        }
      } else {
        // Binary = WAV response from server
        setState("playing");
        try {
          await playWavBuffer(e.data as ArrayBuffer);
        } catch (err) {
          console.error("[Audio] Playback error:", err);
          setError(String(err));
        } finally {
          setState("idle");
        }
      }
    };

    ws.current.onerror = (e) => {
      console.error("[WS] WebSocket error:", e);
      setError("WebSocket connection error");
    };

    ws.current.onclose = () => {
      console.log("[WS] Disconnected");
      setState("idle");
    };
  }, []);

  const stopRecording = useCallback(() => {
    // Always clear the auto-stop timer first
    if (autoStopTimer.current !== null) {
      clearTimeout(autoStopTimer.current);
      autoStopTimer.current = null;
    }
    if (recorder.current && recorder.current.state === "recording") {
      recorder.current.stop();
    }
  }, []);

  const startRecording = useCallback(async () => {
    if (state !== "idle") return;
    if (!ws.current || ws.current.readyState !== WebSocket.OPEN) {
      setError("Not connected to server");
      return;
    }

    try {
      const stream = await navigator.mediaDevices.getUserMedia({ audio: true });
      chunks.current = [];
      recorder.current = new MediaRecorder(stream);

      recorder.current.ondataavailable = (e: BlobEvent) => {
        if (e.data.size > 0) chunks.current.push(e.data);
      };

      recorder.current.onstop = async () => {
        // Stop all tracks to release microphone
        stream.getTracks().forEach((t) => t.stop());

        const blob = new Blob(chunks.current, { type: recorder.current!.mimeType });
        try {
          await captureAndSendAudio(blob, ws.current!);
        } catch (err) {
          console.error("[Audio] Capture/send error:", err);
          setError(String(err));
          setState("idle");
        }
      };

      recorder.current.start();
      setState("recording");
      setError(null);

      // Auto-stop after 30 seconds to prevent oversized payloads (T-01-12 mitigation)
      autoStopTimer.current = window.setTimeout(() => {
        if (recorder.current && recorder.current.state === "recording") {
          console.warn("[useVoiceWS] 30s recording limit reached — auto-stopping");
          stopRecording();
        }
      }, 30_000);
    } catch (err) {
      console.error("[Audio] getUserMedia error:", err);
      setError("Microphone access denied");
    }
  }, [state, stopRecording]);

  return { state, error, connect, startRecording, stopRecording };
}
```

import { useEffect, useCallback } from "react";
import { useVoiceWS } from "./hooks/useVoiceWS.js";

const WS_URL = "/ws"; // Vite proxy routes this to ws://localhost:3001/ws in dev

const STATE_LABELS: Record<string, string> = {
  idle: "Hold to Talk",
  recording: "Recording...",
  processing: "Processing...",
  playing: "Playing...",
};

const STATE_COLORS: Record<string, string> = {
  idle: "#4a9eff",
  recording: "#ff4a4a",
  processing: "#ffa04a",
  playing: "#4aff7a",
};

export default function App() {
  const { state, error, connect, startRecording, stopRecording } = useVoiceWS();

  useEffect(() => {
    connect(WS_URL);
  }, [connect]);

  const handlePress = useCallback(() => {
    startRecording();
  }, [startRecording]);

  const handleRelease = useCallback(() => {
    stopRecording();
  }, [stopRecording]);

  return (
    <div
      style={{
        display: "flex",
        flexDirection: "column",
        alignItems: "center",
        justifyContent: "center",
        minHeight: "100vh",
        fontFamily: "sans-serif",
        background: "#1a1a2e",
        color: "#eee",
        gap: "24px",
      }}
    >
      <h1 style={{ margin: 0, fontSize: "2rem" }}>Oasis</h1>

      <div
        style={{
          fontSize: "1.1rem",
          color: STATE_COLORS[state],
          minHeight: "1.5rem",
        }}
      >
        {STATE_LABELS[state] ?? state}
      </div>

      <button
        onMouseDown={handlePress}
        onMouseUp={handleRelease}
        onMouseLeave={handleRelease}
        onTouchStart={handlePress}
        onTouchEnd={handleRelease}
        disabled={state === "processing" || state === "playing"}
        style={{
          width: "140px",
          height: "140px",
          borderRadius: "50%",
          border: "none",
          background: STATE_COLORS[state],
          cursor: state === "idle" || state === "recording" ? "pointer" : "not-allowed",
          fontSize: "1rem",
          color: "#fff",
          fontWeight: "bold",
          boxShadow:
            state === "recording"
              ? "0 0 0 12px rgba(255,74,74,0.3)"
              : "0 4px 24px rgba(0,0,0,0.4)",
          transition: "all 0.15s ease",
          userSelect: "none",
        }}
      >
        {state === "recording" ? "Release" : "Talk"}
      </button>

      {error && (
        <div
          style={{
            color: "#ff6b6b",
            fontSize: "0.9rem",
            maxWidth: "300px",
            textAlign: "center",
          }}
        >
          {error}
        </div>
      )}
    </div>
  );
}

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser microphone → MediaRecorder → WebSocket | User audio captured in browser, resampled, sent to server |
| server WebSocket → AudioContext → speaker | Server-provided WAV bytes decoded and played |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-10 | Information Disclosure | getUserMedia audio stream | accept | Browser prompts user for mic permission; stream tracks stopped immediately after recording ends |
| T-01-11 | Tampering | Server WAV bytes → decodeAudioData | accept | Malicious server could send crafted audio; this is a LAN-only trusted server scenario in v1 |
| T-01-12 | Denial of Service | Long recordings → large PCM payload | mitigate | `window.setTimeout(stopRecording, 30_000)` in `startRecording` auto-stops recording after 30s; `clearTimeout` in `stopRecording` cancels the timer when user releases manually |
