Then update package.json scripts section to:

```json
"scripts": {
  "dev": "concurrently \"npm run dev:server\" \"npm run dev:client\"",
  "dev:server": "tsx watch src/server/index.ts",
  "dev:client": "vite src/client",
  "build": "npm run build:server && npm run build:client",
  "build:server": "tsc --project tsconfig.server.json",
  "build:client": "vite build src/client",
  "typecheck": "tsc --project tsconfig.server.json --noEmit && tsc --project tsconfig.client.json --noEmit",
  "typecheck:server": "tsc --project tsconfig.server.json --noEmit",
  "typecheck:client": "tsc --project tsconfig.client.json --noEmit",
  "test": "vitest run",
  "test:watch": "vitest"
}
```

The `dev:server` uses `tsx watch` (not ts-node) for fast TypeScript execution.
The `dev:client` passes the client directory directly to vite since vite.config.ts will live there.
`concurrently` runs both in parallel in dev mode.
